# MGN Threads Collective — Storefront

A curated multi-brand t-shirt store demo for **MGN Threads Collective**.

Labels on the rack: Carhartt, Essentials (Fear of God), The North Face, Stüssy,
A Bathing Ape, Human Made, H&M, Cotton On, Uniqlo.

- Single-page static site (`index.html`), no build step
- Working brand filter, cart drawer (localStorage), lookbook strip
- Photography via [Pexels](https://www.pexels.com) (photographers credited in the site footer)
- Demo storefront — checkout is not connected

Live site: https://jelsun1203.github.io/mgn-threads-collective/
